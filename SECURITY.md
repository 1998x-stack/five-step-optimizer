# Security and Safety

This is an analytic decision-support skill, **not a machine control system** and not an authorization for production changes. Do not connect it directly to plant actuators, bypass interlocks or remove legal quality controls. Treat factory logs as confidential; remove credentials, personnel data and production secrets from public cases.

For a security vulnerability in scripts or published example material, use the repository's private vulnerability reporting feature when available; otherwise contact the maintainer without disclosing exploit details in a public issue. This project does not solicit credentials.
