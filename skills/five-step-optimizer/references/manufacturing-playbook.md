# Manufacturing workflow

Start with product/SKU family, plant boundary, work shifts, demand and good-unit definition. Map physical flow and information flow separately. Capture work content, measured cycle time distributions, availability, changeover, failure modes, WIP, constraints, scrap, first-pass yield, maintenance, energy, quality checks and labor/consumables costs.

Do not infer the system bottleneck from a single machine. Use value-stream mapping, Theory of Constraints and quality-adjusted end-to-end throughput. With parallel cells, shared fixtures, queues, rework loops or buffers, the bundled serial model is insufficient: measure real output or use validated discrete-event modeling.

For structural gigacasting, compare only equivalent *rear underbody assemblies*: include die, alloy and melt control, vacuum, mold life, cooling, trimming, machining, nondestructive testing, dimensional metrology, crash/structural verification, replacement parts and repairability. Reduced part count can increase tooling and scrap costs; propose a controlled qualification trial, not a production authorization.
