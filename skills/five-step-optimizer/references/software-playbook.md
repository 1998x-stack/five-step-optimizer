# Software and AI agent workflow

Map issue-to-production lead time, actual engineering work, idle wait, review queue, test duration, deployment window, change failure, recovery time and security findings. Challenge repeated intake templates and approvals only after identifying their control purpose. Keep risk-tiered authorization, security tests, data protection and auditability.

Prefer small reversible patches and tests before adding agent orchestration. Delete unnecessary tool calls, split responsibilities only where justified, simplify data contracts and measure verified task completion rather than number of actions.

Automate only with reliable CI, limited permissions, logs, monitoring, rate limits, review gates for high-risk changes, safe rollback, and explicit user authorization for external side effects.
