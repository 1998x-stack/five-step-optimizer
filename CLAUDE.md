# Five-Step Optimizer

When optimizing a system, read the canonical `skills/five-step-optimizer/SKILL.md`.

Start with the actual objective, source evidence and protected constraints. Then question requirements, remove unnecessary work, simplify the remainder, improve end-to-end throughput and only then automate verified stable processes. Require testable success metrics and explicit adverse-effect/rollback analysis. Never authorize or actuate machinery. Keep changes surgical. Explain blocked decisions and missing information rather than inventing numbers.
